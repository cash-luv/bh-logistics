# BH로지스틱스 통합 배차 · 운행 · 정산 관리 시스템 (Admin Web)

화물 운송 기사용 모바일 앱(Flutter)과 연동되어 실시간 운행 기록, 차량 정비·정기검사, 비업무(사적) 주행 감지, 주유비 분석 및 월 결산 엑셀을 제공하는 본사 관리자용 웹 애플리케이션입니다.

## 주요 기능

1. **종합 KPI 대시보드**: 이달 총매출, 운행 중 차량, 공차(미배정)/대기 차량, 정비 필요 및 정기검사 D-Day 임박 차량, 오늘 출근/미출근 기사 현황, 비업무(사적) 주행 감지 알림
2. **운행 기록 (DailyLogs)**: 월별·기사별·상태별 조회, 우측 상세 슬라이드 패널(출퇴근 계기판 사진, 차량 점검표, 시·구·동 주차 주소 및 상세 지도), 퇴근 누락 보정 및 무효(`void`) 처리
3. **차량 및 정비 관리 (Vehicles & Maintenance)**: 번호판 검색, 검사 D-Day 배지, `runTransaction` 기반 기사↔차량 양방향 배정, 차량 상세(검사 갱신, 주차 장소명 수정, 예정 정비 완료 처리 및 소모품 교체 주행거리 알림)
4. **기사 관리 (Users)**: 관리자가 부여한 기사 ID 코드 + 초기 생년월일 6자리 계정 생성 및 활성/비활성 관리
5. **노선 관리 (Routes)**: 경유지 칩(`대전 → 용인 → 곤지암`) 구성 및 스냅샷 단가 관리
6. **월 결산 · 시각화 · ExcelJS 다운로드**: Recharts 기반 3종 차트(기사별 매출, 일별 추이, 노선별 비율), 월 결산 마감(`Settlements`), ExcelJS 서식(틀 고정·필터·숫자 콤마)이 적용된 4개 시트 엑셀 다운로드

## 사용 기술

- React 18 + Vite + TypeScript + Tailwind CSS
- Firebase Web SDK (Authentication, Cloud Firestore, Cloud Storage)
- Recharts (데이터 시각화), ExcelJS (브라우저 엑셀 생성)

## 실행 방법

```bash
npm install
npm run dev
```
